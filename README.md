## Structura programului
* #### Directorul "structs/" ce contine structurile "incident", "intervention" si "unit". In fisirele de tip header se afla structurile propriu zise si declaratiile unor functii auxiliare pentru a face codul mai lizibil. In fisierele sursa de afla implementarea acestor functii auxiliare.
* #### system.h: Aici este fisierul header in care am creat structura "System" pentru a putea implementa cerinta temei si declararea functiilor/ comenzilor care trebuie implementate.
* #### system.c: Inima programului. Aici sunt implementate toate comenzile.
* #### main.c: Aici se deschid fisierele din care se citesc datele de intrare si se scriu datele de iesire. Totodata, in main.c se proceseaza si tipul cererilor/ comenzilor.
